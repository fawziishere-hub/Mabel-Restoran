# CodeZH - Programming Courses Platform

A modern, responsive programming courses website built with React and Tailwind CSS.

## Features

- **Homepage**: Eye-catching hero section with featured courses and testimonials
- **Courses Listing**: Advanced filtering, search, and sorting functionality
- **Course Details**: Comprehensive course information with curriculum breakdown
- **About Page**: Company information and team showcase
- **Dark/Light Mode**: Toggle between themes with persistent preference
- **Responsive Design**: Mobile-first approach for all screen sizes
- **Smooth Animations**: Framer Motion animations for enhanced UX

## Tech Stack

- React 18
- Tailwind CSS
- Framer Motion
- React Query
- React Toastify
- Embla Carousel
- React Icons
- React Hook Form
- date-fns

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
